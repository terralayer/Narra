# Narra

**Narra** is an audiobook-only Usenet indexer.

Narra scans configured Usenet groups, groups multipart posts into releases, classifies audiobook candidates, stores searchable metadata, generates NZBs from message IDs, and exposes a Newznab-compatible API.

> Development status: `0.1.0-alpha`

The initial implementation is being bootstrapped on the `feature/0.1.0-alpha` branch.
